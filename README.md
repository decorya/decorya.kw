# Decorya ديكوريا — Website

Static, bilingual (Arabic / English) informational website for [@decorya.kw](https://www.instagram.com/decorya.kw/) — parquet, WPC wood alternative, decor panels, stone alternative and wall frames in Kuwait.

- `index.html` — the whole site (no build step)
- `assets/img/` — logo and project photos from the Instagram account

Preview locally: open `index.html` in a browser. Deploy: enable GitHub Pages (Settings → Pages → Deploy from branch `main`, root).

# Floora فلورا — Website

Static, bilingual (Arabic / English) website for Floora — parquet and wood-look flooring in Kuwait, with a filterable product catalog.

- `index.html` — the whole site (no build step); catalog data lives in the `P` array in the script at the bottom
- `assets/img/` — logo, project photos, and `catalog/` floor swatches

Preview locally: open `index.html` in a browser. Deploy: enable GitHub Pages (Settings → Pages → Deploy from branch `main`, root).
